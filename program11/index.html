Grid Takes Over the Front Page

By Soham

CSS Grid lets a page be laid out in rows and columns at the same time. Instead of nudging boxes around with floats, the layout is described once on the container and every story drops into its place.

This lead story is split into text columns using the column-count property, just like a printed paper. The rest of the page uses named grid areas, so the layout can be rearranged in a media query without touching the HTML.

Resize the window and watch the stories move from one column to two, and then to three.
